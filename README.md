# 👥 User Explorer

A lightweight web application built with HTML, CSS, and JavaScript that allows users to load and explore user information through a simple and responsive interface.

## 📌 Overview

User Explorer is a beginner-friendly JavaScript project focused on working with user data and dynamically displaying information on a web page.

The application provides a clean dark-themed interface where users can load user information and view it in individual cards.

## ✨ Features

- Load user data with a button click
- Display users in dynamic cards
- Clean and modern dark-themed UI
- Responsive card layout using CSS Grid
- Interactive hover effects
- Status message area for user feedback

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
